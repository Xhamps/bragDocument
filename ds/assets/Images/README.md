# Images

Artwork cropped from the source kit's renders, for MediaCard and hero imagery. All are dark, saturated violet-blue; they read on both themes.

- `blob.jpg`: the glossy violet 3D blob on black (470 × 285). Course and feature thumbnails.
- `nebula.jpg`: violet starfield glow fading to navy (1024 × 264). Wide banners and overlay cards.
- `sky.jpg`: the hero's blue sky gradient with faint perspective lines (1200 × 233). Light banners.
- `violet.jpg`: lilac light falling over deep violet (480 × 568). Portrait overlay cards.

Use them with `object-fit: cover`; put white text on them only through MediaCard's `overlay` scrim.
