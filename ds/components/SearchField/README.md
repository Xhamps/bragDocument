# SearchField

A pill-shaped glass search input with a trailing magnifier, used in app headers and above lists.

- **Provide** `placeholder` (default "Search"), and `value`/`onChange` or leave it uncontrolled; all input attributes pass through.
- Place it in the header row, left of avatar and actions; minimum width 240px, it grows with its container.
- Don't add a visible label above it; give `label` when the placeholder is not "Search".
