# TextArea

A multi-line glass input for comments and messages ("Reply to comment").

- **Provide** `label`, `value`/`onChange` or `defaultValue`, and `rows` (default 4); it resizes vertically only.
- `hint` and `error` behave as in TextField.
- Keep it inside a Card; pair it with a glass "Reply" or primary "Send" button below, right-aligned.
